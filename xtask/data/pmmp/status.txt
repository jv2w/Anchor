# Status of PMMP API rows (PLAN.md 8.4, 10.8), read by `cargo xtask table`.
#
# One rule per line: `<pattern> <status> <target or reason>`. The pattern and the status each end
# at the first whitespace; the rest of the line is the target or reason. `#` lines and blank
# lines are comments.
#
# Pattern: a row FQN (`pocketmine\player\Player::getName`, a class row `pocketmine\player\Player`)
# where `*` matches any text without `\` or `:` and `**` matches any text, so
# `pocketmine\plugin\**` is a namespace with every class and method in it and
# `pocketmine\block\**::get*` every getter below `pocketmine\block`.
#
# Status:
#   differs <reason>   Anchor has the row's alias but behaves differently, for this reason.
#   merged <alias>     Anchor does the row's work in the item carrying <alias> (an alias in src/);
#                      the row takes that item's location and tests.
#   skipped <reason>   Anchor does not have it, for this reason.
#   open <note>        Anchor does not have it yet and has not decided against it: the row stays
#                      blank with this note (what is missing), and rules below do not decide it.
#
# A row whose alias is on an item in src/ is implemented whatever its first matching rule says;
# only the first `differs` rule matching it applies. Any other row takes the status of the first
# rule matching it. A rule that decides no row is an error, so put narrow rules above broad ones.
#
# Rows no rule decides, and `open` rows, stay blank: they are the API Anchor still lacks or has
# not decided on. A missing feature is never written as skipped without a reason from CLAUDE.md
# or PLAN.md.
